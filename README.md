## 🎯 Course Objectives

- **Python & Data Foundations**: Master core Python structures and numerical computing with NumPy.
- **Data Wrangling**: Clean, filter, reshape, and aggregate tabular data with Pandas.
- **Exploratory Data Analysis**: Create intuitive statistical visualizations using Matplotlib & Seaborn.
- **Machine Learning**: Implement end-to-end Scikit-Learn pipelines (Preprocessing, ColumnTransformer, Train/Test Split, Linear Regression, Logistic Regression, KNN).
